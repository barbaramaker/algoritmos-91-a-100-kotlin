**Algoritmos 91 a 100 em Kotlin**

Este repositório contém os algoritmos de 91 a 100, originalmente escritos em Portugol e convertidos para Kotlin.

O objetivo da atividade é praticar a linguagem Kotlin e aprofundar o uso de estruturas condicionais, operadores relacionais, lógicos e aritméticos, além de manipulação de números inteiros e decimais.

**Algoritmos desenvolvidos**

- Algoritmo 91: Lê dois números inteiros, efetua a adição e apresenta o resultado caso seja maior que 10.
- Algoritmo 92: Efetua a adição de dois números, somando 8 se o resultado for maior que 20 ou subtraindo 5 caso contrário.
- Algoritmo 93: Calcula a raiz quadrada de um número se for positivo ou o seu quadrado se for negativo.
- Algoritmo 94: Verifica se um número lido é ou não múltiplo de 3.
- Algoritmo 95: Verifica se um número lido é ou não divisível por 5.
- Algoritmo 96: Verifica se um número lido é divisível por 3 e por 7 simultaneamente.
- Algoritmo 97: Verifica se um número é divisível por 10, por 5, por 2 ou por nenhum destes através de condicionais aninhadas.
- Algoritmo 98: Valida se o valor de uma prestação ultrapassa 30% do salário bruto para a concessão de um empréstimo.
- Algoritmo 99: Extrai o algarismo da casa das centenas de um número de 3 dígitos e verifica se é par ou ímpar.
- Algoritmo 100: Extrai o número formado pelas casas das unidades de milhar e centenas de um número de 4 dígitos e verifica se é múltiplo de 4.

**Comentários sobre os exercícios**

Neste bloco, consegui consolidar o uso de estruturas condicionais encadeadas e aninhadas (`if`/`else`), além de operações matemáticas específicas para divisão inteira e obtenção de restos (`%` / operador módulo).

Também aprendi a extrair partes específicas de números inteiros utilizando divisão posicional e a aplicar regras de negócio em validações financeiras e matemáticas.

Os exercícios ajudaram a compreender melhor como traduzir estruturas de decisão do Portugol para o Kotlin de forma idiomática e limpa.

**Ferramentas utilizadas**

- Kotlin
- IntelliJ IDEA
- Git e GitHub

**Organização**

Os arquivos estão organizados individualmente, de Algoritmo91.kt até Algoritmo100.kt, dentro da pasta src/main/kotlin.

Cada arquivo contém o enunciado, o código original em Portugol e sua conversão para Kotlin.
